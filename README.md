# Git Practice

Repositorio de prueba para aprender Git y GitHub desde Visual Studio Code.

## Objetivos

- Aprender a utilizar Git.
- Gestionar versiones de archivos.
- Sincronizar repositorios con GitHub.

## Progreso

- Primer repositorio creado.
- Primer commit realizado.
- Primera sincronización con GitHub completada.

## Comandos básicos de Git

- `git status`: muestra el estado del repositorio y los cambios pendientes.
- `git add`: prepara archivos modificados para incluirlos en el próximo commit.
- `git commit`: guarda un conjunto de cambios preparados en el historial local.
- `git push`: envía los commits locales al repositorio remoto.
- `git pull`: obtiene e integra los cambios del repositorio remoto.
